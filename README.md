# Preview Image Saver

在影片頁按右下角「下載圖片」，將封面與全部預覽圖存到指定資料夾。

## 支援網站

| 網站 | 影片頁網址 | 番號來源 | 圖片來源 |
|------|-----------|---------|---------|
| JavDB | `javdb.com/v/*` | 頁面「番號」欄 | `c0.jdbstatic.com` 封面與預覽原圖 |
| JavLibrary | `www.javlibrary.com/*`（頁面有封面時才顯示按鈕） | `#video_id` 識別碼 | `pics.dmm.co.jp` 封面與預覽大圖（`jp-N`） |
| JavTrailers | `javtrailers.com/video/*` | 頁面「DVD ID」 | `pics.dmm.co.jp` 封面與預覽大圖（`jp-N`） |

JavTrailers 是單頁應用，按下按鈕時會重新抓取當前網址的 HTML 解析圖片清單，所以從站內連結換頁也能正常下載。

演員名來源（只取第一位）：JavDB 為「演員」欄的 `a.actor-female`（沒有則取其他演員連結）；JavLibrary 為 `#video_cast .star a`；JavTrailers 為 `Cast(s):` 那行的連結，文字如「Kana Mito 水戸かな」，只保留第一個非 ASCII 字元起的日文名。找不到演員時只用番號。

## 輸出結構

```
<根資料夾>\<YYYYMMDD>\<演員> <番號>\
    <番號>_cover.jpg
    <番號>_01.jpg
    <番號>_02.jpg
    ...
```

演員名只加在資料夾名，圖片檔名只用番號。例如：`...\B_poses\20261018\水戸かな JUVR-212\JUVR-212_01.jpg`；找不到演員時為 `...\B_poses\20261018\JUVR-212\JUVR-212_01.jpg`。選圖視窗的標題也會顯示「演員 番號」。

## 安裝

1. 開啟 `chrome://extensions/`，啟用右上角「開發人員模式」
2. 點「載入未封裝項目」，選擇本資料夾
3. 首次安裝會自動開啟教學幻燈片，在「步驟 1」選好根資料夾（例如 `ComfyUI\input\B_poses`）
4. 到任一支援網站的影片頁，點右下角「下載圖片」

之後想換資料夾或重新授權，點瀏覽器右上角的擴充功能圖示即可；彈出視窗底部的「查看教學」可重看幻燈片。

## 使用方式

- **下載圖片**：預設一鍵下載封面與全部預覽圖。
- **下載前先選擇圖片**（設定開關，預設關閉）：在教學頁第 3 步或點工具列圖示的彈出視窗中開啟。開啟後，按「下載圖片」會先跳出縮圖視窗，預設全選，勾選要的圖片後按「下載已選」。只下載部分圖片時，檔名沿用圖片在網站上的原始編號（例如只選第 3、7 張，會存成 `DEVR-018_03.jpg`、`DEVR-018_07.jpg`），之後補下載其他張不會撞名。
- **滑鼠停留自動放大**（設定開關，預設開啟）：選圖視窗中，滑鼠在縮圖上停留 0.5 秒會放大顯示原圖，移開即收起；可在教學頁第 3 步或彈出視窗關閉。放大時會在頁面的 Console 記錄原圖實際解析度（`[PreviewImageSaver] 放大 ...`）。
- **彈出框可縮放、可移動**：選圖視窗右下角有縮放把手，用滑鼠拖曳即可放大縮小；縮圖固定 5 欄，所以縮圖會跟著框的大小變化（最小約 420 px 寬）。拖曳標題列可移動位置，不會被拖出畫面。大小與位置不會記住，每次開啟都回到預設大小（寬 900 px、高為視窗 80%）並置中。
- **偵測人臉與依臉佔比篩選**：選圖視窗一開啟就自動偵測（需先開啟「下載前先選擇圖片」），每張縮圖上會用方框框出每一個頭（含額頭、頭髮與耳朵），多人時各自一個框；比例顯示在縮圖右上角（不蓋住人臉），多人時由大到小列出、最多 3 個，其餘顯示「+N」，顏色與框一致（綠＝達標、橘＝未達標）。偵測完成後出現兩個下拉選單可切換比例的算法（偵測只做一次，切換即時重算、不用重新偵測，選擇會記住）：框選範圍選「五官框（模型原始，預設）」或「頭部框（含頭髮）」；計算方式選「邊長比（面積比開根號，不受圖片長寬比影響，預設）」、「面積比（框面積÷圖面積）」、「高度比（框高÷圖高）」或「寬度比（框寬÷圖寬）」。預設的五官框＋邊長比適合換臉挑圖：邊長比 × √(圖寬×圖高) 即臉的邊長像素（例如 1280×720 的圖，15% 約 144 px），門檻起點為 15%，再依實際換臉效果調整。面積比的數字偏小，滑桿上限 50，其餘為 100。另有「臉佔比 ≥ N%」滑桿，達標的框為綠色、未達標為橘色；偵測完成時不會改動勾選（預設仍全選），拖動滑桿才會勾選「最大的那張臉 ≥ N%」的圖、取消其餘，之後仍可手動增減再按「下載已選」。偵測失敗時標題列按鈕會顯示「偵測失敗，重試」。偵測以縮圖進行，全程在本機執行，不會上傳圖片。
- 按鈕可以用滑鼠拖曳到喜歡的位置，位置依網站各自記住。

## 檔案說明

| 檔案 | 用途 |
|------|------|
| `manifest.json` | MV3 設定：`storage`、`offscreen` 權限與圖床的 host 權限，不使用 `downloads`；CSP 加上 `'wasm-unsafe-eval'` 供人臉偵測的 WebAssembly 使用 |
| `content.js` | 在影片頁插入可拖曳的浮動按鈕，擷取番號、封面與預覽圖網址；選圖視窗（含臉框疊圖與臉佔比篩選） |
| `background.js` | Service Worker：整批抓圖並寫入已授權的資料夾；資料夾未設定或授權過期時自動開啟設定視窗；首次安裝時開啟教學頁；依選圖視窗需求建立／關閉 offscreen 偵測頁面 |
| `offscreen.html` / `offscreen.js` | Offscreen document：抓縮圖、用 MediaPipe 偵測人臉，回傳正規化的頭部框與面積比例（service worker 沒有 canvas，頁面端讀不到跨網域像素） |
| `vendor/mediapipe/` | `@mediapipe/tasks-vision` 1.1.1（Apache-2.0）的 JS 與 wasm，以及 `blaze_face_short_range.tflite` 模型；MV3 不允許載入遠端程式碼，所以隨擴充功能打包 |
| `popup.html` / `popup.js` | 點工具列圖示的彈出視窗：選擇資料夾、重新授權、「下載前先選擇圖片」開關 |
| `welcome.html` / `welcome.css` / `welcome.js` | 首次安裝的精靈式教學（7 步：功能、選資料夾、下載方式、臉佔比篩選、釘選、支援網站、完成） |
| `settings.js` | 使用者設定（`chrome.storage.sync`：下載前選圖、停留放大）的讀寫，彈出視窗與教學頁共用 |
| `folder-ui.js` | 彈出視窗與教學頁共用的資料夾選擇／授權邏輯 |
| `store.js` | 將根資料夾 handle 存入 IndexedDB（background 與頁面共用） |
| `theme.css` | 彈出視窗樣式（含深色模式）；教學頁另用 `welcome.css`（FANZA 風格淺色主題） |
| `icons/` | 擴充功能圖示（`icon.svg` 為原始檔，PNG 為各尺寸輸出） |

## 已知限制

- 以 File System Access API 寫檔，不使用 `downloads` 權限。
- Chrome 重啟後，資料夾授權可能失效；此時會自動彈出設定視窗，按「重新授權」後再下載一次。授權提示若有「每次造訪時允許」請選它，可免去天天重新授權。
- 不改用 `chrome.downloads`：若 Chrome 開了「下載前詢問每個檔案的儲存位置」，下載 API 會忽略指定路徑並每張跳另存視窗，無法建立日期／番號資料夾與改名。
- 彈出視窗內的「選擇資料夾」若遇到彈窗被關閉而存不下來，請改在教學頁（重新安裝或開啟 `welcome.html`）的步驟 1 選擇。
- 人臉偵測使用 BlazeFace short-range 模型，針對近距離、較大的臉；畫面中太小的臉可能偵測不到而沒有框（實測臉寬約為圖寬 8% 時就漏抓，約 15% 以上穩定偵測得到）。模型本身只框眉毛到下巴的五官區域，頭部框是依五官框外推（左右各 14%、上緣往上 48.5% 框高、下緣內縮 7%，見 `offscreen.js` 的 `HEAD_PAD`）；外推量是依一張特寫封面上手畫的目標框反推的經驗值，不同臉型、髮型、側臉或低頭會有誤差。預設比例是五官框的邊長比（面積比開根號）；切換成頭部框時才用到上述外推。
- 同名檔案直接覆寫。
- 單張圖片失敗不會中斷整批，結果會顯示成功與失敗張數。
